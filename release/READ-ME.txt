Token info 1.3.0 - Windows x64

1. Extract the entire ZIP archive into a folder you want to keep.
2. Double-click Token info.exe.
3. Optional: run Create desktop shortcut.vbs.

Choose your language at the top of the app. English, Norwegian Bokmal,
Swedish, Danish, German, French and Spanish are included. Your choice is saved.

Codex must be installed and signed in for account data. No separate Node,
npm or API key is required. Local usage uses logs on your own PC.
Claude CLI logs are not supported.

To upgrade, close the old app and extract this version into a new folder.
Run the new shortcut script to update your desktop shortcut.
Existing TI settings and custom project folders are retained.

The executable is unsigned. Windows may show a warning.
Check that the download comes from the project's GitHub release.
The release includes SHA256SUMS.txt to verify the ZIP.

Close the window to exit, or minimize it to keep monitoring.
No personal logs or credentials are included in this package.
